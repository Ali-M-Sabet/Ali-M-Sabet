# Ali Mohamed Sabet

**RTL design · Digital verification · FPGA development**

I'm a final-year Communication and Computer Engineering student at Cairo University, graduating in June 2027. I work on digital hardware projects spanning processor design, signal processing, bus interfaces, and hardware acceleration, with an emphasis on self-checking verification and fixed-point modeling.

My current graduation project is a team effort developing a Kyber accelerator, covering key generation, encapsulation, and decapsulation.

## Selected work

- **[16-point FFT](https://github.com/Ali-M-Sabet/fft16-r2sdf)** — Radix-2 SDF architecture in SystemVerilog, with a MATLAB fixed-point reference and self-checking verification. Passed 105 bit-exact tests against the fixed-point model.
- **[AHB-Lite master and interconnect](https://github.com/Ali-M-Sabet/ahb-lite-master)** — 32-bit master and two-slave interconnect, with SystemVerilog integration tests covering pipelined transfers, wait states, and error recovery.
- **[Six-stage pipelined CPU](https://github.com/Ali-M-Sabet/Pipelined-32-bit-CPU)** — Team project implementing a custom-ISA processor in VHDL, with forwarding, hazard handling, branch prediction, interrupt support, and a Python assembler.
- **[64-QAM transceiver](https://github.com/Ali-M-Sabet/64qam-transceiver)** — MATLAB baseband simulation comparing ZF, MMSE, LMS, and NLMS equalization, including fixed-point and mixed-precision experiments.
- **[Full-duplex UART](https://github.com/Ali-M-Sabet/Full-Duplex-UART)** — Configurable parity, receiver oversampling and majority voting, with self-checking verification.
- **[BERT accelerator contribution](https://github.com/Ali-M-Sabet/BERT_AI_HW_Accelerator)** — Developed a 32-lane fixed-point GELU block in SystemVerilog within a team accelerator project, with directed arithmetic and GELU tests.
